


    
    BACK-OFFICE ADMINISTRATEUR — CENTRE DE PILOTAGE DE LA PLATEFORME

    
    1. OBJECTIF

    LE BACK-OFFICE ADMINISTRATEUR EST LE CENTRE DE CONTRÔLE DE TOUTE LA PLATEFORME.

    IL DOIT PERMETTRE DE :

    GÉRER LES DONNEURS D’ORDRE ;

    GÉRER LES TRANSPORTEURS ;

    VALIDER LES INSCRIPTIONS ;

    CONTRÔLER LES RFQ ;

    SUIVRE LES COTATIONS ;

    VALIDER LES RECOMMANDATIONS ;

    GÉRER LES AFFAIRES CONFIRMÉES ;

    SUIVRE LES COMMISSIONS ;

    GÉRER LES INCIDENTS ;

    SUIVRE LES PAYS ;

    EXPLOITER LES CONTACTS INTERNATIONAUX ;

    ANALYSER LES DONNÉES COMMERCIALES ;

    PILOTER L’EXPANSION INTERNATIONALE ;

    GARDER UNE TRAÇABILITÉ COMPLÈTE.

    LE PRINCIPE RESTE :

    
    LA PLATEFORME CALCULE.

    
    
    L’ADMINISTRATEUR CONTRÔLE.

    
    
    L’ADMINISTRATEUR DÉCIDE.
