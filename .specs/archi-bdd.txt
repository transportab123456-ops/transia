


    
    ARCHITECTURE DE LA BASE DE DONNÉES

    
    1. OBJECTIF

    LA BASE DE DONNÉES DOIT ÊTRE CONÇUE DÈS LE DÉPART POUR SUPPORTER :

    PLUSIEURS PAYS ;

    PLUSIEURS LANGUES ;

    PLUSIEURS DEVISES ;

    PLUSIEURS TYPES D’ENTREPRISES ;

    PLUSIEURS UTILISATEURS PAR ENTREPRISE ;

    PLUSIEURS CONTACTS PAR ENTREPRISE ;

    PLUSIEURS MODES DE TRANSPORT ;

    DES MILLIERS PUIS DES MILLIONS DE RFQ ;

    UN HISTORIQUE COMPLET DES COTATIONS ;

    LE CALCUL DES COMMISSIONS ;

    LA TRAÇABILITÉ ;

    L’EXPANSION INTERNATIONALE.

    LE PRINCIPE TECHNIQUE EST SIMPLE :

    
    UNE INFORMATION IMPORTANTE NE DOIT PAS ÊTRE DUPLIQUÉE PARTOUT.

    ELLE DOIT ÊTRE STOCKÉE UNE SEULE FOIS, PUIS RELIÉE AUX AUTRES ÉLÉMENTS.
